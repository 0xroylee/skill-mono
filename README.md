# skill-mono

Roy's collection of agent skills. Each directory under `skills/` contains a `SKILL.md` entry point.

| Skill | Purpose |
| --- | --- |
| [paseo-plan-build-review](skills/paseo-plan-build-review/SKILL.md) | Coordinate planning, Fast development, independent review and replanning in Paseo. |
| [pr-review-with-screenshots](skills/pr-review-with-screenshots/SKILL.md) | Verify Paseo UI changes against screenshots of the frozen review candidate. |

Keep the two skills in sibling directories when installing them together. The planner also uses the separately installed `codebase-design` skill.
